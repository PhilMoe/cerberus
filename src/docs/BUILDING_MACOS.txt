BUILDING INSTRUCTIONS FOR APPLE MAC OS X

PLEASE NOTE:
Before you begin. You should check out one of the desktop sub forums for any issues and workarounds, or to ask questions.
https://www.cerberus-x.com/community/categories/desktop-targets.70/

BASIC REQUIREMENTS:
An Apple computer running at a support version of macOS. At the time of this documents creation, a minimum of macOS 13 (Ventura) and xcode 14.3.
A Z SHELL command line terminal.

THE IDE TED REQUIREMENTS:
A Qt SDK installation with a Qt SDK kit from Qt6.5 onwards supporting a Qt Web Engine.

BUILDING:
There is a build script supplied in the Cerberus source directory called builder.zsh.
This script has two modes of operation. When run without options, the default is to build all tools providing that the requirement above are met. The second mode is used to display a menu
where all the tools can be built individually. Selection between modes is determined by the --showmenu/-m option listed further down in these instructions.

To build Cerberus X, or one of the base tools, open a command line console, navigate to the Cerberus source (src) directory and type:
./builder.zsh
Or
./builder.zsh -m

Please note that the transcc tool needs to be built first for any of the main Cerberus X tools applications.

To build the IDE requires that there is a Qt SDK installation installed correctly, with a Qt development kit and that kit supports Qt Web Engine.
If not, then the menu entry for building the IDE Ted will not be shown and building all tools will exclude the building of the IDE Ted.
If there is an official Qt installer, then you can pass arguments to select it's root directory and a specific version using the options --qtsdk and --qtkit.
Executing the builder.zsh script will look for the Qt install at $HOME/Qt. If it is detected and no parameter is passed to select a kit,
or kit passed as a parameter was not found. Then it will try to select the highest kit available. If there is no Qt install, or any qt kit available, then the IDE will not be built. 


The optional arguments to pass to the builder.sh script for the official Qt Installer are:
-q or --qtsdk with the full path to the Qt Installers directory.
-k or --qtkit with the dot version number for a specific Qt SDK.
-p or --prefix with a name for a bundle identifier prefix. The default is com.cerberus-x. NOTE: Current only for the IDE Ted.
-m or --showmenu will run the script in menu mode.
-d or --deploy with the full path to where Cerberus will be built and an archive created. NOTE: This requires that git is installed and is only available in menu mode.
--clearbuilds to remove all built files and exit. This also removes those for other systems leaving a clean git repository.
-h or --help to shows help info.

There are three options that are displayed when the --help option is selected. And should be considered experimental.
-t or --tedsign forces the codesign -s - on Ted. Use this if Ted keeps giving problems of asking for access to the disk.
-c or --codesign with the full path to a codesign certificate. NOTE: That this is only for the IDE Ted and is passed to the macdeployqt tool at the end of building. 
-a or --archive Set the archive tool. The default is to use hdiutil. This is currently not implemented and may be removed due to how Apple certification works.

DEPLOYING:
The deployment of Cerberus requires knowledge of the code signing process.
Information about this can be found on the Apple developers website and documentation.
https://developer.apple.com/
